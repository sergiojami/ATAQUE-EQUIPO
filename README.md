# Aviónica v4 conectada a Supabase

La aplicación está configurada con el proyecto Supabase proporcionado.

Incluye selección de los empleados reales de `profiles`, lectura de cuadrantes/inventario/noticias/novedades y operaciones básicas de administración.

IMPORTANTE: el PIN 1234 es solo una demostración. Antes de publicar hay que configurar RLS/policies correctamente y cambiar el mecanismo de administración.

No uses nunca una `service_role`/secret key en el frontend.
